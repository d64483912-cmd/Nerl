# PWA Icons

This directory should contain the following icon files for the Progressive Web App:

- `icon-192.png` - 192x192 pixel icon
- `icon-512.png` - 512x512 pixel icon
- `apple-touch-icon.png` - Apple touch icon
- `favicon.ico` - Browser favicon

## Icon Requirements

### Design Guidelines
- Use the Nelson-GPT brand colors (amber #F59E0B)
- Include a medical/stethoscope symbol
- Ensure good contrast and readability at small sizes
- Follow PWA icon best practices

### Technical Specifications
- **192x192**: Standard PWA icon size
- **512x512**: High-resolution PWA icon (also used as maskable)
- **Apple Touch Icon**: 180x180 for iOS devices
- **Favicon**: 32x32 ICO format for browsers

### Tools for Icon Generation
- [PWA Builder](https://www.pwabuilder.com/imageGenerator)
- [Favicon Generator](https://favicon.io/)
- [App Icon Generator](https://appicon.co/)
